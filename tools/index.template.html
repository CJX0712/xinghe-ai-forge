⚡ 用法

同一份 src/ai-forge.js，浏览器 <script> 直接全局 AIForge，Node require() 即用。
// Node / 浏览器通用
const AI = typeof module !== 'undefined' ? require('./src/ai-forge.js') : window.AIForge;

// 线性回归（正规方程 + Cholesky）
const lr = new AI.LinearRegression().fit(X, y);
lr.predict([1.2, -0.5]);            // → ŷ

// 深度学习：反向传播 + 梯度检验
const net = new AI.MLP({ layers:[2,16,3], activation:'relu', output:'softmax' });
net.fit(X, y, { epochs:120 });

// 运行 17 项不变量自检
const r = AI.selftest();
console.log(r.passed + '/' + r.total, r.allPass ? '全绿' : '有失败');

📚 数学与算法依据

  • Golub & Van Loan, Matrix Computations — Householder QR、SVD、Jacobi 族的收敛与精度。
  • Numerical Recipes (Press et al.) — 循环 Jacobi 对称特征值分解的经典稳定实现。
  • Bishop, Pattern Recognition and Machine Learning §9.2 — GMM 的 EM、logsumexp 稳定对数似然。
  • Goodfellow et al., Deep Learning — 反向传播、中心差分梯度检验、Adam。
  • Vaswani et al. 2017, Attention Is All You Need — 缩放点积多头注意力。
  • Platt 1998 — Sequential Minimal Optimization（SVM 对偶分解）。
  • Arthur & Vassilvitskii 2007 — k-means++ 初始化；Breiman 1984 — CART。
